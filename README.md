CAMPUS.LIVE 🏫

Smart College Classroom & Lecture Management System

CAMPUS.LIVE is a college management application designed to help Principals, HODs and Teachers monitor classroom activities, manage lectures and coordinate timetable changes.

🎯 Objective

To make college lecture management smarter, faster and more organized through a centralized digital platform.

👥 Authorized Users

- Principal / Main Admin
- Head of Department (HOD)
- Teachers

Students do not have login access.

✨ Key Features

- Department-wise management
- Year and division-wise classroom organization
- Digital lecture timetables
- Live lecture start and end status
- Teacher information and lecture assignments
- Lecture rescheduling and teacher swapping
- Notifications for timetable changes
- Classroom monitoring dashboard

💻 Technologies

- HTML
- CSS
- JavaScript
- Firebase (planned integration)

🚀 Project Vision

To create a centralized platform where college authorities can monitor classroom activities and teachers can coordinate lectures without unnecessary confusion.
